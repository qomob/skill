## 关于我们

Qomob 是一家 AI × Marketing × Business 的实践团队，base 上海。

我们相信：值得被 AI 复制的不是某个 Prompt，而是一个专业人士判断问题、解决问题的方法。当一个专家的判断可以被拆解、验证和封装，它就能从个人经验变成组织能力。

所以我们不卖"AI 工具清单"，而是从真实业务问题出发，帮企业找到值得 AI 化的问题，并把答案交付成可复用、可运行的 AI 能力。

## 我们解决什么问题

| 表面问题 | 真实问题 |
|---|---|
| 企业买了很多 AI 工具 | 缺少适配自身业务的应用路径 |
| 团队里有人很会用 AI | 方法停在个人身上，人走经验走 |
| AI 能生成内容 | 没有接上真实业务目标，产生不了持续价值 |

## 三条业务线

**AI Strategy — 发现 AI 机会**
识别最值得 AI 化的业务场景，输出应用路径与团队成熟度评估。AI 战略咨询 / 业务流程分析 / AI 应用规划。

**AI Growth — 让 AI 进入增长**
把 AI 用在营销、内容和品牌增长上。AI 内容营销 / GEO 搜索增长 / 创始人 IP / 营销自动化工作流 / 增长策略优化。

**AI System — 把经验变成系统**
把企业知识、专业流程和工作方法沉淀为可持续运行的系统。AI Skill / AI Agent / Workflow / Knowledge Base / MCP Integration。

## 我们怎么交付

我们以 **Skill** 作为最小交付单元：把一段专家判断写成结构化、可评估、可版本化、可嵌入工作流的指令包，再组装成 Agent 与 Workflow，接入企业真实流程。

> 经验 → 流程 → Skill → Agent / Workflow → 生产环境

判断标准只有一个：交付之后，它是否真的在业务里跑。
